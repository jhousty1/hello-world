# Day 1 — Linux 与云运维入门

## 🇨🇳 中文

### 今天学什么

今天正式开始学习 Linux 与云运维。

### 今天学习的知识

- 什么是 Linux
- 什么是服务器
- Linux 在服务器中的作用
- Linux 为什么广泛应用于云计算和服务器
- 什么是 Terminal（终端）
- 什么是 Shell
- Linux 命令行的基本概念

### 今天的实践

开始接触 Linux 终端，并尝试使用基础 Linux 命令。

通过命令行与 Linux 系统进行交互，初步理解服务器管理为什么大量依赖命令行。

### 今天的理解

以前我对服务器的理解比较模糊。

今天开始了解到：

**Linux 是现代服务器和云计算环境中非常重要的基础。**

云服务器本质上也是一台运行在数据中心里的计算机，而 Linux 是管理这些服务器的重要操作系统之一。

因此，如果想继续学习 Cloud、DevOps 和 SRE，Linux 是必须掌握的基础。

### 今日总结

Day 1 正式开始。

今天没有追求学习大量命令，而是先建立 Linux、服务器、终端和 Shell 的基本概念。

接下来会逐渐从基础命令进入文件系统、权限、网络、SSH、Web 服务以及云服务器等内容。

I started using the Linux terminal and practiced some basic Linux commands.

Before today, I did not have a clear understanding of servers.

Today I learned that:

**Linux is an important foundation for modern servers and cloud computing.**

Therefore, Linux is an essential foundation for learning Cloud, DevOps, and SRE.

### Summary

Today was Day 1 of my learning journey.

Instead of trying to learn many commands at once, I focused on understanding the basic concepts of Linux, servers, terminals, and shells.
